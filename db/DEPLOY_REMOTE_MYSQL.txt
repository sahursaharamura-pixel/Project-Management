HƯỚNG DẪN: Đưa MySQL database "pman" lên server 10.147.0.36
để website chạy trên IIS tại 10.147.18.15 kết nối vào
════════════════════════════════════════════════════════════

Chuẩn bị: copy file "pman-full-dump.sql" (cùng thư mục với file này)
sang server 10.147.0.36.

────────────────────────────────────────────────────────────
BƯỚC 1: Nếu MySQL chưa cài trên 10.147.0.36
────────────────────────────────────────────────────────────
Cài MySQL Server 8.0 (Server only là đủ), đặt mật khẩu root khi cài.
Tải tại: https://dev.mysql.com/downloads/installer/

────────────────────────────────────────────────────────────
BƯỚC 2: Nạp dữ liệu (schema + toàn bộ dữ liệu thật)
────────────────────────────────────────────────────────────
Mở CMD trên 10.147.0.36, chạy (đường dẫn mysql.exe có thể khác tuỳ bản cài):

  "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p < pman-full-dump.sql

Nhập mật khẩu root khi được hỏi. Lệnh này tự tạo database "pman"
và nạp toàn bộ bảng + dữ liệu thật vào.

Kiểm tra:
  mysql -u root -p -e "USE pman; SELECT COUNT(*) FROM projects; SELECT COUNT(*) FROM items;"
  → Phải thấy: 3 dự án, 51 hạng mục

────────────────────────────────────────────────────────────
BƯỚC 3: Tạo tài khoản riêng cho ứng dụng (KHÔNG dùng root)
────────────────────────────────────────────────────────────
Chạy trong mysql client (đăng nhập bằng root). Mật khẩu bên dưới đã
được điền sẵn khớp với file config.iis.js — chỉ cần copy nguyên văn:

  CREATE USER 'pman_app'@'10.147.18.15' IDENTIFIED BY 'jyxlYSsI3fZFEqNq!Bb2';
  GRANT ALL PRIVILEGES ON pman.* TO 'pman_app'@'10.147.18.15';
  FLUSH PRIVILEGES;

  (Tài khoản này CHỈ được phép kết nối từ đúng IP 10.147.18.15,
   và chỉ có quyền trên database "pman" — không đụng tới
   database "evngenco2_schedule" hay bất cứ database nào khác.)

────────────────────────────────────────────────────────────
BƯỚC 4: Cho phép MySQL lắng nghe kết nối từ mạng (không chỉ localhost)
────────────────────────────────────────────────────────────
1. Mở file cấu hình (thường ở):
   C:\ProgramData\MySQL\MySQL Server 8.0\my.ini
2. Tìm dòng "bind-address", sửa thành:
   bind-address = 0.0.0.0
   (hoặc để đúng IP 10.147.0.36 nếu máy có nhiều card mạng)
3. Lưu file, khởi động lại dịch vụ MySQL:
   Mở PowerShell (Run as Administrator):
   Restart-Service MySQL80

────────────────────────────────────────────────────────────
BƯỚC 5: Mở Firewall — CHỈ cho phép đúng IP của web server
────────────────────────────────────────────────────────────
Mở PowerShell (Run as Administrator) trên 10.147.0.36:

  New-NetFirewallRule -DisplayName "MySQL pman - IIS server" `
    -Direction Inbound -Protocol TCP -LocalPort 3306 `
    -RemoteAddress 10.147.18.15 -Action Allow

────────────────────────────────────────────────────────────
BƯỚC 6: Kiểm tra kết nối từ xa
────────────────────────────────────────────────────────────
Trên máy 10.147.18.15 (IIS server), mở PowerShell, chạy:

  Test-NetConnection -ComputerName 10.147.0.36 -Port 3306

→ Phải thấy: TcpTestSucceeded : True
Nếu False → kiểm tra lại Bước 4 (bind-address) và Bước 5 (firewall).
